GIULIO ADVICE SITE - QUICK START

VITE DEVELOPMENT
1. Install Node.js 20.19 or newer.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev

QUICK STATIC PREVIEW
Run:
   npm run serve:static

Then open:
   http://127.0.0.1:8080/
