# Museum layout JSON package

Extract this ZIP at the root of the Vite project.

It will create:
src/json/scene-objects/*.json

The objects are compatible with the current JSON loader/builder if it supports:
- box
- sphere
- plane
- position
- rotationDegrees
- color
- title/description as harmless metadata

No images are required. Letters, stamps, postcards, seals, doors, walls, and statue parts are represented with colored placeholder shapes.

The central hall is represented with a square placeholder floor and many small wall segments approximating a circular wall. The statue is a golden placeholder built from primitive shapes.
